Execute Phase 4 of the SDLC Orchestrator Suite using the `sdlc-debug` skill.

1. Triage the reported bug and trace data flow without guessing (`_engine-triage-issue`, `_engine-systematic-debugging`).
2. Formulate falsifiable hypotheses and isolate root cause.
3. Enforce Chesterton's Fence before altering existing logic.
4. Author a failing reproduction test first (`_engine-test-driven-development`).
5. Apply minimal targeted fix and verify with full test suite.
